FANDOOM BACKEND — ENDPOINT CONTRACT
Olusturulma tarihi: 2026-08-10
Kapsam: src/main/java/.../*/controller/ altindaki TUM controller'lar (23 adet)

Rol notasyonu:
  PUBLIC     -> auth gerekmez
  AUTH       -> herhangi bir rolle login yeterli (SecurityConfig'te ozel kural yok)
  EDITOR+    -> hasAnyRole(EDITOR, MODERATOR, ADMIN)
  ADMIN      -> hasRole(ADMIN)

Genel kural (common/config/SecurityConfig.java):
  - Butun modullerde GET => PUBLIC, yazma (POST/PUT/PATCH/DELETE) => EDITOR+
    (asagida modul basina ayrica yazilmadi, sadece istisnalar not edildi)
  - Istisnalar: /api/cms/** yazma => ADMIN, /api/users/** tumu => ADMIN,
    /api/media/** tumu (GET yok zaten) => EDITOR+, /api/auth/** register-login-
    resend-verification-verify-email => PUBLIC, logout/me => AUTH,
    /api/productions/** => PUBLIC (yazma endpoint'i yok)

       HIC cagirmaz.
     - "Watchlist" — POST /api/me/saved-items (listType verilmez/WATCHLIST,
       varsayilan) — "izlemeyi planliyorum".
     - "Watched" — POST /api/me/saved-items (listType=WATCHED) —
       "izledim". Watchlist'te bir kayit varsa OTOMATIK SILINIR (Trakt/
       Letterboxd modeli: izlendi = artik izlenecekler listesinde degil).

14c. SAVED ITEM  (Watchlist / Readlist / Watched / Custom liste uyeligi —
     "Save"/Bookmark icin BUNU DEGIL, 14f'yi kullanin)
--------------------------------------------------------------------------
POST   /api/me/saved-items                                           AUTH
  Body    : SaveItemRequest{ itemId*(Long), itemType*(SavedItemType),
             targetListId(Long, opsiyonel), listType(ListType, opsiyonel —
             WATCHLIST|READLIST|WATCHED, CUSTOM GECERSIZ), notes<=500 }
  Response: UserSavedItemResponse{ id, itemId, itemType,
             progressPercentage(Integer), notes, createdAt }
  Status  : 201
  Status  : 400 (InvalidReferenceException) — itemId gecersizse, VEYA
             listType=CUSTOM gonderilirse (CUSTOM icin targetListId
             kullanilmali).
  Not     : targetListId verilirse (CUSTOM liste dahil) o liste kullanilir.
             Yoksa: listType verilmisse o sistem listesi (ör. "Izledim"
             butonu -> listType=WATCHED), verilmemisse itemType'a gore
             varsayilan (BLOG->READLIST, MOVIE|SERIES->WATCHLIST — "Izleme
             Listeme Ekle" butonu, listType hic gonderilmez). listType=WATCHED
             ile eklenen bir oge, WATCHLIST'te varsa OTOMATIK silinir.

PATCH  /api/me/saved-items/{id}                                      AUTH
  Body    : UpdateSavedItemRequest{ progressPercentage(0-100, Integer,
             sadece BLOG icin anlamli — MOVIE/SERIES'de gonderilse bile
             reddedilmez, salt bilgi amacli saklanir), notes<=500 }
  Response: UserSavedItemResponse
  Status  : 200
  Not     : Bu iki alan icin @Valid UYGULANIR (Min/Max/Size, null=degismedi
             zaten her ikisi de wrapper/opsiyonel oldugu icin celiski yok).

DELETE /api/me/saved-items/{id}                                      AUTH
  Status  : 204

GET    /api/me/saved-items/status/{itemType}/{itemId}                AUTH
  Query   : listType(ListType, opsiyonel — verilmezse itemType'in
             varsayilanina gore: BLOG->READLIST, MOVIE|SERIES->WATCHLIST;
             "Izlendi mi?" sormak icin listType=WATCHED verin)
  Response: SavedItemStatusResponse{ saved(bool), savedItemId(Long|null) }
  Status  : 200
  Not     : Sorgulanan listType'a gore degerlendirilir — oge sadece baska
             bir listede (ör. CUSTOM, ya da WATCHLIST sorgulanirken sadece
             WATCHED'teyse) kayitliysa false doner. DELETE /me/saved-items/{id}
             savedItemId ister (itemId DEGIL), bu yuzden boolean tek basina
             yetmez.

HATA FORMATI (tum endpoint'lerde ortak — GlobalExceptionHandler)
================================================================================
ResourceNotFoundException          -> 404
InvalidReferenceException          -> 400
DuplicateResourceException         -> 409
InvalidFileException               -> 400
TranslationIncompleteException     -> 400 (alan hatalariyla, fieldErrors)
PartialUpdateValidationException   -> 400 (alan hatalariyla, fieldErrors —
                                        PATCH /api/me/profile ve
                                        PATCH /api/me/lists/{id}'de kullanilir,
                                        bkz. 14. ACCOUNT)
MethodArgumentNotValidException    -> 400 (alan hatalariyla, @Valid basarisiz)
DataIntegrityViolationException    -> 409 (DB kisit ihlali)
(Yakalanmayan her sey)              -> 500

Govde formati (ApiErrorResponse):
{
  "timestamp": "<ISO-8601 LocalDateTime>",
  "status": <int>,
  "error": "<HTTP reason phrase, orn. \"Bad Request\">",
  "message": "<aciklama>",
  "path": "<istek path'i>",
  "fieldErrors": ["<alan>: <hata mesaji>", ...] | null   // sadece validasyon
                                                           // hatalarinda dolu,
                                                           // duz string LISTESI
                                                           // (obje/map DEGIL)
}
